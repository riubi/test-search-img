# Поиск общих ключевых точек на нескольких изображениях

Домашнее задание по компьютерному зрению. Есть 6 снимков рачка *Bosmina longirostris* (разные особи),
нужно найти ключевые точки, которые соответствуют одним и тем же местам организма на всех снимках.

Основной метод - SIFT (OpenCV), для сравнения ORB, AKAZE, BRISK.

Отчёт: [report.pdf](report.pdf)

## Что делается

1. Предобработка: серое изображение, маска организма, приведение организма к одному размеру,
   CLAHE, отражение снимков 2, 3, 5 (рачки смотрят в другую сторону, а SIFT не инвариантен к отражению).
2. SIFT внутри маски + прореживание близких точек.
3. Попарное сопоставление: окно поиска, тест Лоу, взаимная проверка, проверка масштаба,
   RANSAC (модель подобия), уточнение.
4. Общие точки: опорное изображение, совмещение остальных с ним, поиск соответствий для каждой точки
   опорного снимка, пересечение по всем снимкам.
5. Рисунки: одна и та же точка имеет один номер и цвет на всех снимках.

## Запуск

```
pip install -r requirements.txt
python common_points.py     # основной результат -> results/
python experiments.py       # параметры, сравнение методов, синтетический тест -> results/experiments/
```

## Файлы

- `common_points.py` - весь конвейер
- `experiments.py` - эксперименты для отчёта
- `images/` - исходные снимки
- `results/common_points.png` - точки, общие для всех 6 снимков
- `results/common_points_partial.png` - точки, найденные хотя бы на 4 из 6 снимков
- `results/summary.json` - числа: точки, соответствия по парам, координаты общих точек
- `results/experiments/` - графики и таблицы экспериментов
- `report.pdf` - отчёт

## Результат (SIFT)

| | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| найдено точек | 3372 | 3682 | 2645 | 3871 | 3297 | 486 |
| после прореживания | 1400 | 1510 | 1219 | 1449 | 1342 | 357 |

Опорный снимок - 2. Соответствий с ним: 205, 233, 202, 204, 63 (снимки 1, 3, 4, 5, 6).
Общих для всех 6 снимков точек - 1 (слабая, в зависимости от параметров 0 или 1), не меньше чем на 5 из 6 - 3, не меньше чем на 4 из 6 - 26.
